# Milestone 1 · Skeleton — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A running VisualStore container with login, multiple profiles backed by per-profile SQLite databases under versioned migrations, a table-driven job scheduler with a compute process pool, scheduled verified backups, and a browser shell (login, profile management, overview).

**Architecture:** One FastAPI server process owns every database connection and runs I/O jobs in a worker thread; a `multiprocessing` pool of child processes runs compute jobs and talks to the server only through queues. A `ProfileRegistry` maps profile names to directories under `/data/profiles/<name>/` and keeps each profile's `visualstore.db` and `vectors.db` migrated. The React frontend is built into `visualstore/static/` and served by the same process.

**Tech Stack:** Python 3.12, FastAPI, uvicorn, stdlib `sqlite3` (WAL), hand-written SQL migrations, `multiprocessing` (spawn), pytest + httpx; React 18 + TypeScript + Vite + react-router, vitest, Playwright; `uv` for Python packaging, multi-stage Dockerfile (linux/amd64 + linux/arm64), GitHub Actions publishing to GHCR.

**Spec:** `docs/design/` — chiefly [02 Architecture](../design/02-architecture.md), [03 Data Model §5.1 Profile/Job/Setting, §5.2, §5.3](../design/03-data-model.md), [04 Job System](../design/04-jobs.md), [07 Operations](../design/07-operations.md), [09 Project Layout](../design/09-project-layout.md), [11 Roadmap §13 item 1](../design/11-roadmap.md#13-milestones). Decisions specific to this milestone are recorded in [ADR-0003](../decisions/0003-m1-implementation-choices.md) (written in Task 16).

## Global Constraints

- Python `>=3.12`. Package name `visualstore`. Everything user-facing is named VisualStore; the predecessor is "ImageStore" or "v1" ([ADR-0001](../decisions/0001-rename-to-visualstore.md)).
- Environment variables, exactly: `VISUALSTORE_DATA_DIR` (default `/data`), `VISUALSTORE_BACKUP_DIR` (default `/backups`), `VISUALSTORE_PASSWORD` (required; server refuses to start without it and says why), `VISUALSTORE_COMPUTE_PROCESSES` (default CPU count), `VISUALSTORE_PORT` (default `8080`).
- Per-profile files: `/data/profiles/<name>/visualstore.db`, `vectors.db`, `index.usearch`, `thumbs/`. Global: `/data/global.db`. Backups: `/backups/<profile>/`, `/backups/global.db`.
- Profile `name` matches `^[a-z0-9]+(-[a-z0-9]+)*$` and doubles as directory name and URL segment. Deleting a profile removes its whole directory and requires the name to be typed as confirmation.
- Every primary key is a UUID stored as a 16-byte BLOB, generated in the application.
- Every connection sets `PRAGMA foreign_keys = ON`, `journal_mode = WAL`, `synchronous = NORMAL`.
- Only the server process opens database connections. Compute children receive `ComputeRequest` objects and return `ComputeMessage` objects over queues; they never receive a path to a database.
- Nothing under `/data` records a host path or machine identity.
- Schema changes go through numbered migration files `NNNN_name.sql`; migrations run per database (global, profile metadata, vectors) at start-up and when a profile is created.
- Job state machine: `queued → running → done | failed | cancelled`; a job interrupted or failed fewer than 3 times returns to `queued` with `attempts + 1`; the third failure sets `failed`. `running` jobs found at start-up are treated as interrupted.
- Priority is an integer, higher runs first, ties broken by `created_at` ascending, across all profiles. Constants: user-triggered 100, inbox 50, archive 20, maintenance 0.
- Session cookie `visualstore_session`: HttpOnly, SameSite=Lax, HMAC-SHA256 signed with a 32-byte key generated on first start and stored in `global.db`. Password comparison is constant-time. Login failures are rate-limited per client address.
- Backup defaults (profile settings): `backup.metadata.interval_hours = 24`, `backup.metadata.keep = 14`, `backup.vectors.interval_hours = 168`, `backup.vectors.keep = 4`. Every backup copy passes `PRAGMA integrity_check` or is deleted and the job fails.
- UI strings are English and live in the components; no runtime language switching.
- Commit messages: Conventional Commits (`feat:`, `test:`, `chore:`, `docs:`), each ending with the line `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.
- Documentation lives only under `docs/` ([ADR-0002](../decisions/0002-documentation-structure.md)).

## Review Focus

Inputs the spec implies but that would bite a person if untested. Each has a pinned test in the task that owns the code.

1. **A profile name that is a path (`../other`, `a/b`, `..`) or has uppercase letters** must be rejected before any filesystem access, both in `ProfileRegistry.create` and at the API, so nothing can be created or deleted outside `/data/profiles/`. (Task 5 step 1, Task 11 step 1.)
2. **A container restart while jobs are `running`** must return them to `queued` with `attempts` incremented, and the third interruption must leave them `failed` and visible instead of looping forever. (Task 3 step 1, Task 8 step 1.)
3. **A job whose `type` no handler knows** (typo in the API, or a type from a later milestone) must become `failed` with a clear error at once, not be retried three times. (Task 8 step 1.)
4. **A backup taken while the live database is being written** must be a consistent copy that opens and passes integrity check; and a corrupt copy must be deleted, not kept as a "backup". (Task 9 step 1.)
5. **A session cookie that is expired, tampered with, or signed with another instance's key** must be rejected with 401, never cause a 500. (Task 6 step 1, Task 10 step 1.)

```python
"""Process-wide configuration read from environment variables.

Everything else that can be changed at runtime is a per-profile Setting
(see visualstore.db.settings); only what the process needs before it can
open a database lives here.
"""

from __future__ import annotations

import os
from collections.abc import Mapping
from dataclasses import dataclass
from pathlib import Path


class ConfigError(Exception):
    """The environment does not describe a runnable configuration."""


@dataclass(frozen=True)
class Config:
    data_dir: Path
    backup_dir: Path
    password: str
    compute_processes: int
    port: int

    @classmethod
    def from_env(cls, env: Mapping[str, str] | None = None) -> Config:
        env = os.environ if env is None else env
        password = env.get("VISUALSTORE_PASSWORD", "")
        if not password:
            raise ConfigError(
                "VISUALSTORE_PASSWORD is not set. VisualStore refuses to start without a "
                "login password; set the environment variable and restart the container."
            )
        return cls(
            data_dir=Path(env.get("VISUALSTORE_DATA_DIR") or "/data"),
            backup_dir=Path(env.get("VISUALSTORE_BACKUP_DIR") or "/backups"),
            password=password,
            compute_processes=_positive_int(
                env, "VISUALSTORE_COMPUTE_PROCESSES", os.cpu_count() or 1
            ),
            port=_positive_int(env, "VISUALSTORE_PORT", 8080),
        )


def _positive_int(env: Mapping[str, str], key: str, default: int) -> int:
    raw = env.get(key)
    if raw is None or raw == "":
        return default
    try:
        value = int(raw)
    except ValueError:
        raise ConfigError(f"{key} must be a positive integer, got {raw!r}") from None
    if value < 1:
        raise ConfigError(f"{key} must be a positive integer, got {raw!r}")
    return value
```

```python
"""Open SQLite files with the pragmas every VisualStore database uses (design §5.3)."""

import sqlite3
from pathlib import Path


def connect(path: Path) -> sqlite3.Connection:
    path.parent.mkdir(parents=True, exist_ok=True)
    # check_same_thread=False: the server process uses connections from the event-loop
    # thread and from the single io-job worker thread, never concurrently on one connection.
    conn = sqlite3.connect(path, check_same_thread=False)
    conn.row_factory = sqlite3.Row
    conn.execute("PRAGMA foreign_keys = ON")
    conn.execute("PRAGMA journal_mode = WAL")
    conn.execute("PRAGMA synchronous = NORMAL")
    return conn
```

`visualstore/db/migrate.py`:

```python
"""Versioned schema migrations: numbered SQL files applied in order, one transaction each."""

from __future__ import annotations

import re
import sqlite3
from pathlib import Path

from visualstore.clock import now_iso

_FILE_NAME = re.compile(r"^(\d{4})_[a-z0-9_]+\.sql$")
_ROOT = Path(__file__).parent / "migrations"


def migrations_dir(name: str) -> Path:
    """Directory of the shipped migrations for one database kind: global, profile, vectors."""
    directory = _ROOT / name
    if not directory.is_dir():
        raise ValueError(f"no migrations shipped for database kind {name!r}")
    return directory


def list_migrations(directory: Path) -> list[tuple[int, Path]]:
    found: list[tuple[int, Path]] = []
    for path in sorted(directory.glob("*.sql")):
        match = _FILE_NAME.match(path.name)
        if match is None:
            raise ValueError(f"migration file name not understood: {path.name}")
        found.append((int(match.group(1)), path))
    versions = [v for v, _ in found]
    if versions != list(range(1, len(versions) + 1)):
        raise ValueError(
            f"migrations in {directory} must be numbered 0001.. without gaps, got {versions}"
        )
    return found


def current_version(conn: sqlite3.Connection) -> int:
    conn.execute(
        "CREATE TABLE IF NOT EXISTS schema_version ("
        " version INTEGER PRIMARY KEY, applied_at TEXT NOT NULL)"
    )
    row = conn.execute("SELECT MAX(version) AS v FROM schema_version").fetchone()
    return int(row["v"] or 0)


def migrate(conn: sqlite3.Connection, directory: Path) -> int:
    version = current_version(conn)
    for number, path in list_migrations(directory):
        if number <= version:
            continue
        sql = path.read_text(encoding="utf-8")
        # executescript commits any pending transaction and then runs the script verbatim,
        # so the BEGIN/COMMIT pair below is what makes one migration atomic.
        script = (
            "BEGIN;\n"
            f"{sql}\n"
            f"INSERT INTO schema_version (version, applied_at) VALUES ({number}, '{now_iso()}');\n"
            "COMMIT;"
        )
        try:
            conn.executescript(script)
        except sqlite3.Error:
            if conn.in_transaction:
                conn.rollback()
            raise
        version = number
    return version
```

```python
"""Query functions for the job table (design §5.1 Job, §6.1)."""

from __future__ import annotations

import json
import sqlite3

from visualstore.clock import now_iso
from visualstore.ids import id_to_str, new_id

MAX_ATTEMPTS = 3
STATES = ("queued", "running", "done", "failed", "cancelled")


def enqueue(
    conn: sqlite3.Connection,
    *,
    type: str,
    kind: str,
    params: dict | None = None,
    priority: int = 0,
) -> bytes:
    job_id = new_id()
    with conn:
        conn.execute(
            "INSERT INTO job (id, type, params, state, priority, kind, created_at)"
            " VALUES (?, ?, ?, 'queued', ?, ?, ?)",
            (job_id, type, json.dumps(params or {}), priority, kind, now_iso()),
        )
    return job_id


def get(conn: sqlite3.Connection, job_id: bytes) -> sqlite3.Row | None:
    return conn.execute("SELECT * FROM job WHERE id = ?", (job_id,)).fetchone()


def list_jobs(
    conn: sqlite3.Connection, state: str | None = None, limit: int = 100
) -> list[sqlite3.Row]:
    if state is None:
        return conn.execute(
            "SELECT * FROM job ORDER BY created_at DESC, rowid DESC LIMIT ?", (limit,)
        ).fetchall()
    return conn.execute(
        "SELECT * FROM job WHERE state = ? ORDER BY created_at DESC, rowid DESC LIMIT ?",
        (state, limit),
    ).fetchall()


def count_by_state(conn: sqlite3.Connection) -> dict[str, int]:
    counts = dict.fromkeys(STATES, 0)
    for row in conn.execute("SELECT state, COUNT(*) AS n FROM job GROUP BY state"):
        counts[row["state"]] = row["n"]
    return counts


def next_queued(conn: sqlite3.Connection, kind: str) -> sqlite3.Row | None:
    return conn.execute(
        "SELECT * FROM job WHERE state = 'queued' AND kind = ?"
        " ORDER BY priority DESC, created_at ASC, rowid ASC LIMIT 1",
        (kind,),
    ).fetchone()


def has_active(conn: sqlite3.Connection, type: str) -> bool:
    row = conn.execute(
        "SELECT 1 FROM job WHERE type = ? AND state IN ('queued', 'running') LIMIT 1", (type,)
    ).fetchone()
    return row is not None


def mark_running(conn: sqlite3.Connection, job_id: bytes) -> None:
    with conn:
        conn.execute(
            "UPDATE job SET state = 'running', started_at = ?, error = NULL WHERE id = ?",
            (now_iso(), job_id),
        )


def set_progress(conn: sqlite3.Connection, job_id: bytes, progress: dict) -> None:
    with conn:
        conn.execute("UPDATE job SET progress = ? WHERE id = ?", (json.dumps(progress), job_id))


def mark_done(conn: sqlite3.Connection, job_id: bytes) -> None:
    with conn:
        conn.execute(
            "UPDATE job SET state = 'done', finished_at = ? WHERE id = ?", (now_iso(), job_id)
        )


def mark_failed(conn: sqlite3.Connection, job_id: bytes, error: str) -> None:
    """Final failure with no retry, for errors that cannot be fixed by running again."""
    with conn:
        conn.execute(
            "UPDATE job SET state = 'failed', error = ?, finished_at = ? WHERE id = ?",
            (error, now_iso(), job_id),
        )


def record_failure(conn: sqlite3.Connection, job_id: bytes, error: str) -> str:
    """Count one failed attempt. Returns the new state: 'queued' to retry, 'failed' when spent."""
    row = get(conn, job_id)
    attempts = int(row["attempts"]) + 1
    state = "queued" if attempts < MAX_ATTEMPTS else "failed"
    finished = None if state == "queued" else now_iso()
    with conn:
        conn.execute(
            "UPDATE job SET state = ?, attempts = ?, error = ?, finished_at = ? WHERE id = ?",
            (state, attempts, error, finished, job_id),
        )
    return state


def requeue_interrupted(conn: sqlite3.Connection) -> int:
    """At start-up: every job left 'running' by the previous process was interrupted."""
    rows = conn.execute("SELECT id FROM job WHERE state = 'running'").fetchall()
    for row in rows:
        record_failure(conn, row["id"], "interrupted by restart")
    return len(rows)


def retry(conn: sqlite3.Connection, job_id: bytes) -> bool:
    with conn:
        cur = conn.execute(
            "UPDATE job SET state = 'queued', attempts = 0, error = NULL,"
            " started_at = NULL, finished_at = NULL WHERE id = ? AND state = 'failed'",
            (job_id,),
        )
    return cur.rowcount == 1


def cancel(conn: sqlite3.Connection, job_id: bytes) -> bool:
    with conn:
        cur = conn.execute(
            "UPDATE job SET state = 'cancelled', finished_at = ? WHERE id = ? AND state = 'queued'",
            (now_iso(), job_id),
        )
    return cur.rowcount == 1


def to_dict(row: sqlite3.Row) -> dict:
    d = dict(row)
    d["id"] = id_to_str(row["id"])
    d["params"] = json.loads(row["params"])
    d["progress"] = json.loads(row["progress"])
    return d
```

```python
"""Per-profile key-value settings with code-defined defaults (design §5.1 Setting)."""

from __future__ import annotations

import json
import sqlite3
from typing import Any

DEFAULTS: dict[str, Any] = {
    "backup.metadata.interval_hours": 24,
    "backup.metadata.keep": 14,
    "backup.vectors.interval_hours": 168,
    "backup.vectors.keep": 4,
}


def get(conn: sqlite3.Connection, key: str) -> Any:
    if key not in DEFAULTS:
        raise KeyError(key)
    row = conn.execute("SELECT value FROM setting WHERE key = ?", (key,)).fetchone()
    return DEFAULTS[key] if row is None else json.loads(row["value"])


def set(conn: sqlite3.Connection, key: str, value: Any) -> None:  # noqa: A001 - mirrors get()
    if key not in DEFAULTS:
        raise KeyError(key)
    if type(value) is not type(DEFAULTS[key]):
        raise TypeError(
            f"setting {key!r} expects {type(DEFAULTS[key]).__name__}, got {type(value).__name__}"
        )
    with conn:
        conn.execute(
            "INSERT INTO setting (key, value) VALUES (?, ?)"
            " ON CONFLICT(key) DO UPDATE SET value = excluded.value",
            (key, json.dumps(value)),
        )


def all(conn: sqlite3.Connection) -> dict[str, Any]:  # noqa: A001 - mirrors get()
    effective = dict(DEFAULTS)
    for row in conn.execute("SELECT key, value FROM setting"):
        if row["key"] in effective:
            effective[row["key"]] = json.loads(row["value"])
    return effective
```

```python
A profile is the unit of data isolation (design §5.1 Profile, §5.2). The registry is the
only object that knows where a profile's files are; everything else asks it.
"""

from __future__ import annotations

import re
import secrets
import shutil
import sqlite3
from dataclasses import dataclass
from pathlib import Path

from visualstore.clock import now_iso
from visualstore.db.connection import connect
from visualstore.db.migrate import migrate, migrations_dir

PROFILE_NAME_RE = re.compile(r"^[a-z0-9]+(?:-[a-z0-9]+)*$")


class ProfileError(Exception):
    """Invalid input: bad name, duplicate, wrong confirmation."""


class ProfileNotFound(ProfileError):
    pass


@dataclass(frozen=True)
class ProfileInfo:
    name: str
    display_name: str
    created_at: str
    sort_order: int


@dataclass(frozen=True)
class ProfilePaths:
    root: Path

    @property
    def metadata_db(self) -> Path:
        return self.root / "visualstore.db"

    @property
    def vectors_db(self) -> Path:
        return self.root / "vectors.db"

    @property
    def index(self) -> Path:
        return self.root / "index.usearch"

    @property
    def thumbs(self) -> Path:
        return self.root / "thumbs"


def validate_name(name: str) -> None:
    if not PROFILE_NAME_RE.match(name or ""):
        raise ProfileError(
            "Profile names use lowercase letters, digits and single hyphens between them."
        )


class ProfileRegistry:
    def __init__(self, data_dir: Path) -> None:
        self.data_dir = data_dir
        self._global: sqlite3.Connection | None = None
        self._metadata: dict[str, sqlite3.Connection] = {}
        self._vectors: dict[str, sqlite3.Connection] = {}

    # -- lifecycle ---------------------------------------------------------------------

    @property
    def global_db_path(self) -> Path:
        return self.data_dir / "global.db"

    @property
    def profiles_dir(self) -> Path:
        return self.data_dir / "profiles"

    def open(self) -> None:
        self.profiles_dir.mkdir(parents=True, exist_ok=True)
        self._global = connect(self.global_db_path)
        migrate(self._global, migrations_dir("global"))
        for info in self.list():
            self._open_profile(info.name)

    def close(self) -> None:
        for conn in (*self._metadata.values(), *self._vectors.values()):
            conn.close()
        self._metadata.clear()
        self._vectors.clear()
        if self._global is not None:
            self._global.close()
            self._global = None

    def global_conn(self) -> sqlite3.Connection:
        if self._global is None:
            raise RuntimeError("ProfileRegistry is not open")
        return self._global

    def _open_profile(self, name: str) -> None:
        paths = self.paths(name)
        paths.thumbs.mkdir(parents=True, exist_ok=True)
        metadata = connect(paths.metadata_db)
        migrate(metadata, migrations_dir("profile"))
        vectors = connect(paths.vectors_db)
        migrate(vectors, migrations_dir("vectors"))
        self._metadata[name] = metadata
        self._vectors[name] = vectors

    def _close_profile(self, name: str) -> None:
        for store in (self._metadata, self._vectors):
            conn = store.pop(name, None)
            if conn is not None:
                conn.close()

    # -- queries -----------------------------------------------------------------------

    def list(self) -> list[ProfileInfo]:
        rows = self.global_conn().execute(
            "SELECT name, display_name, created_at, sort_order FROM profile"
            " ORDER BY sort_order, created_at"
        )
        return [ProfileInfo(**dict(r)) for r in rows]

    def names(self) -> list[str]:
        return [p.name for p in self.list()]

    def exists(self, name: str) -> bool:
        row = self.global_conn().execute(
            "SELECT 1 FROM profile WHERE name = ?", (name,)
        ).fetchone()
        return row is not None

    def get(self, name: str) -> ProfileInfo:
        row = self.global_conn().execute(
            "SELECT name, display_name, created_at, sort_order FROM profile WHERE name = ?",
            (name,),
        ).fetchone()
        if row is None:
            raise ProfileNotFound(f"profile {name!r} does not exist")
        return ProfileInfo(**dict(row))

    def paths(self, name: str) -> ProfilePaths:
        validate_name(name)
        return ProfilePaths(root=self.profiles_dir / name)

    def conn(self, name: str) -> sqlite3.Connection:
        try:
            return self._metadata[name]
        except KeyError:
            raise ProfileNotFound(f"profile {name!r} does not exist") from None

    def vectors_conn(self, name: str) -> sqlite3.Connection:
        try:
            return self._vectors[name]
        except KeyError:
            raise ProfileNotFound(f"profile {name!r} does not exist") from None

    def usage_bytes(self, name: str) -> int:
        root = self.paths(name).root
        self.get(name)
        return sum(p.stat().st_size for p in root.rglob("*") if p.is_file())

    # -- mutations ---------------------------------------------------------------------

    def create(self, name: str, display_name: str = "") -> ProfileInfo:
        validate_name(name)
        if self.exists(name):
            raise ProfileError(f"profile {name!r} already exists")
        g = self.global_conn()
        order = g.execute("SELECT COALESCE(MAX(sort_order), 0) + 1 FROM profile").fetchone()[0]
        with g:
            g.execute(
                "INSERT INTO profile (name, display_name, created_at, sort_order)"
                " VALUES (?, ?, ?, ?)",
                (name, display_name or name, now_iso(), order),
            )
        self._open_profile(name)
        return self.get(name)

    def rename(self, name: str, display_name: str) -> ProfileInfo:
        self.get(name)
        g = self.global_conn()
        with g:
            g.execute(
                "UPDATE profile SET display_name = ? WHERE name = ?", (display_name or name, name)
            )
        return self.get(name)

    def delete(self, name: str, confirm_name: str) -> None:
        self.get(name)
        if confirm_name != name:
            raise ProfileError("Type the profile name exactly to confirm deletion.")
        self._close_profile(name)
        root = self.paths(name).root
        if root.exists():
            shutil.rmtree(root)
        g = self.global_conn()
        with g:
            g.execute("DELETE FROM profile WHERE name = ?", (name,))

    # -- secrets -----------------------------------------------------------------------

    def secret(self, key: str) -> bytes:
        """A random 32-byte value created on first use and kept in global.db."""
        g = self.global_conn()
        row = g.execute("SELECT value FROM secret WHERE key = ?", (key,)).fetchone()
        if row is not None:
            return bytes(row["value"])
        value = secrets.token_bytes(32)
        with g:
            g.execute("INSERT INTO secret (key, value) VALUES (?, ?)", (key, value))
        return value
```

```python
"""Single-password login primitives (design §9.2): signed sessions, constant-time compare,
per-client failure rate limiting. No database access; the signing key comes from the caller."""

from __future__ import annotations

import base64
import hashlib
import hmac
import time


def _b64(raw: bytes) -> str:
    return base64.urlsafe_b64encode(raw).rstrip(b"=").decode("ascii")


def _unb64(text: str) -> bytes:
    padding = "=" * (-len(text) % 4)
    return base64.urlsafe_b64decode(text + padding)


class SessionSigner:
    """Tokens are `<expiry>.<hmac>`; the expiry is the only payload, so there is no user id."""

    def __init__(self, key: bytes, ttl_seconds: int = 30 * 24 * 3600) -> None:
        if len(key) < 16:
            raise ValueError("session key must be at least 16 bytes")
        self._key = key
        self.ttl_seconds = ttl_seconds

    def _sign(self, payload: bytes) -> bytes:
        return hmac.new(self._key, payload, hashlib.sha256).digest()

    def issue(self, now: float | None = None) -> str:
        now = time.time() if now is None else now
        payload = str(int(now + self.ttl_seconds)).encode("ascii")
        return f"{_b64(payload)}.{_b64(self._sign(payload))}"

    def verify(self, token: str, now: float | None = None) -> bool:
        now = time.time() if now is None else now
        try:
            payload_text, sig_text = token.split(".")
            payload = _unb64(payload_text)
            signature = _unb64(sig_text)
        except (ValueError, TypeError):
            return False
        if not hmac.compare_digest(signature, self._sign(payload)):
            return False
        try:
            expiry = int(payload.decode("ascii"))
        except (ValueError, UnicodeDecodeError):
            return False
        return expiry > now


def password_matches(expected: str, given: str) -> bool:
    return hmac.compare_digest(expected.encode("utf-8"), given.encode("utf-8"))


class LoginRateLimiter:
    """In-memory sliding window per client key. State is lost on restart, which is fine."""

    def __init__(self, max_failures: int = 5, window_seconds: float = 60) -> None:
        self.max_failures = max_failures
        self.window_seconds = window_seconds
        self._failures: dict[str, list[float]] = {}

    def _recent(self, key: str, now: float) -> list[float]:
        cutoff = now - self.window_seconds
        recent = [t for t in self._failures.get(key, []) if t > cutoff]
        if recent:
            self._failures[key] = recent
        else:
            self._failures.pop(key, None)
        return recent

    def allowed(self, key: str, now: float | None = None) -> bool:
        now = time.time() if now is None else now
        return len(self._recent(key, now)) < self.max_failures

    def record_failure(self, key: str, now: float | None = None) -> None:
        now = time.time() if now is None else now
        self._failures.setdefault(key, []).append(now)

    def reset(self, key: str) -> None:
        self._failures.pop(key, None)
```

```python
import os
from collections.abc import Callable

Report = Callable[[dict], None]
Handler = Callable[[dict, Report], dict]


def ping(params: dict, report: Report) -> dict:
    count = int(params.get("count", 1))
    for i in range(count):
        report({"done": i + 1, "total": count, "message": "ping"})
    return {"pong": params.get("echo"), "pid": os.getpid()}


def fail(params: dict, report: Report) -> dict:
    raise RuntimeError(str(params.get("message", "requested failure")))
```

```python
"""Entry point of one compute child: take requests, run handlers, send messages back."""

from __future__ import annotations

from visualstore.jobs.compute.handlers import HANDLERS
from visualstore.jobs.compute.protocol import ComputeMessage, ComputeRequest


def worker_main(in_q, out_q) -> None:
    while True:
        request: ComputeRequest | None = in_q.get()
        if request is None:  # shutdown sentinel
            return

        def report(progress: dict, _req: ComputeRequest = request) -> None:
            out_q.put(ComputeMessage(_req.job_id, _req.profile, "progress", progress))

        try:
            handler = HANDLERS.get(request.type)
            if handler is None:
                raise KeyError(f"unknown compute job type {request.type!r}")
            result = handler(request.params, report)
            out_q.put(ComputeMessage(request.job_id, request.profile, "result", result))
        except Exception as exc:  # noqa: BLE001 - every failure must reach the server
            out_q.put(
                ComputeMessage(
                    request.job_id,
                    request.profile,
                    "error",
                    {"error": f"{type(exc).__name__}: {exc}"},
                )
            )
```

```python
"""Fixed-size pool of compute children fed over multiprocessing queues (design §3, §6.4)."""

from __future__ import annotations

import multiprocessing as mp
import queue

from visualstore.jobs.compute.protocol import ComputeMessage, ComputeRequest
from visualstore.jobs.compute.worker import worker_main


class ComputePool:
    def __init__(self, size: int) -> None:
        if size < 1:
            raise ValueError("pool size must be at least 1")
        self.size = size
        # spawn: children start from a clean interpreter, so no inherited database handles
        # or event loop state (the server's sqlite connections must never cross this line).
        self._ctx = mp.get_context("spawn")
        self._in = None
        self._out = None
        self._procs: list = []

    def start(self) -> None:
        self._in = self._ctx.Queue()
        self._out = self._ctx.Queue()
        self._procs = [
            self._ctx.Process(
                target=worker_main,
                args=(self._in, self._out),
                name=f"visualstore-compute-{i}",
                daemon=True,
            )
            for i in range(self.size)
        ]
        for proc in self._procs:
            proc.start()

    def stop(self, timeout: float = 5.0) -> None:
        if self._in is None:
            return
        for _ in self._procs:
            self._in.put(None)
        for proc in self._procs:
            proc.join(timeout)
            if proc.is_alive():
                proc.terminate()
                proc.join(1.0)
        self._in.close()
        self._out.close()
        self._in = None
        self._out = None

    def submit(self, request: ComputeRequest) -> None:
        if self._in is None:
            raise RuntimeError("pool is not running")
        self._in.put(request)

    def poll(self) -> list[ComputeMessage]:
        if self._out is None:
            return []
        messages: list[ComputeMessage] = []
        while True:
            try:
                messages.append(self._out.get_nowait())
            except queue.Empty:
                return messages

    def alive_count(self) -> int:
        return sum(1 for p in self._procs if p.is_alive())

    def pids(self) -> list[int]:
        return [p.pid for p in self._procs if p.pid is not None]
```

```python
"""Table-driven job scheduler (design §6).

One coroutine polls every profile's job table, hands compute jobs to the process pool and
io jobs to a single worker thread, and persists whatever the pool reports. It is the only
code that moves a job between states while the server is running.
"""

from __future__ import annotations

import asyncio
import json
import logging
import sqlite3
import time
from collections.abc import Callable, Sequence
from dataclasses import dataclass
from pathlib import Path
from typing import Protocol

from visualstore.db import jobs as jobs_db
from visualstore.db import settings as settings_db
from visualstore.ids import id_from_str, id_to_str
from visualstore.jobs.compute.handlers import HANDLERS as COMPUTE_HANDLERS
from visualstore.jobs.compute.protocol import ComputeMessage, ComputeRequest
from visualstore.profiles import ProfileNotFound, ProfilePaths, ProfileRegistry

log = logging.getLogger(__name__)


@dataclass
class IoContext:
    profile: str
    paths: ProfilePaths
    backup_dir: Path
    global_db_path: Path
    settings: dict
    params: dict
    report: Callable[[dict], None]  # thread-safe; may be called from the handler's thread


IoHandler = Callable[[IoContext], dict]
Planner = Callable[[ProfileRegistry], None]


class ComputeBackend(Protocol):
    size: int

    def submit(self, request: ComputeRequest) -> None: ...
    def poll(self) -> list[ComputeMessage]: ...
    def alive_count(self) -> int: ...


class Scheduler:
    def __init__(
        self,
        registry: ProfileRegistry,
        pool: ComputeBackend,
        io_handlers: dict[str, IoHandler],
        backup_dir: Path,
        planners: Sequence[Planner] = (),
        poll_interval: float = 0.5,
        plan_interval: float = 60.0,
    ) -> None:
        self.registry = registry
        self.pool = pool
        self.io_handlers = io_handlers
        self.backup_dir = backup_dir
        self.planners = list(planners)
        self.poll_interval = poll_interval
        self.plan_interval = plan_interval
        self.in_flight: dict[str, str] = {}  # compute job id (str) -> profile name
        self._io_task: asyncio.Task | None = None
        self._loop_task: asyncio.Task | None = None
        self._last_plan: float | None = None

    # -- lifecycle ---------------------------------------------------------------------

    def requeue_interrupted(self) -> int:
        total = 0
        for name in self.registry.names():
            total += jobs_db.requeue_interrupted(self.registry.conn(name))
        if total:
            log.info("requeued %d job(s) interrupted by the previous run", total)
        return total

    async def start(self) -> None:
        self._loop_task = asyncio.create_task(self._run(), name="visualstore-scheduler")

    async def stop(self) -> None:
        if self._loop_task is not None:
            self._loop_task.cancel()
            try:
                await self._loop_task
            except asyncio.CancelledError:
                pass
            self._loop_task = None
        await self.wait_io()

    async def _run(self) -> None:
        while True:
            try:
                await self.tick()
            except Exception:  # noqa: BLE001 - the loop must survive any single bad tick
                log.exception("scheduler tick failed")
            await asyncio.sleep(self.poll_interval)

    async def tick(self) -> None:
        self._drain_pool()
        self._dispatch_compute()
        self._dispatch_io()
        self._plan()

    async def wait_io(self) -> None:
        if self._io_task is not None:
            await self._io_task

    # -- picking -----------------------------------------------------------------------

    def _pick(self, kind: str) -> tuple[str, sqlite3.Row] | None:
        best: tuple[tuple[int, str], str, sqlite3.Row] | None = None
        for name in self.registry.names():
            row = jobs_db.next_queued(self.registry.conn(name), kind)
            if row is None:
                continue
            key = (-int(row["priority"]), str(row["created_at"]))
            if best is None or key < best[0]:
                best = (key, name, row)
        return None if best is None else (best[1], best[2])

    # -- compute -----------------------------------------------------------------------

    def _dispatch_compute(self) -> None:
        while len(self.in_flight) < self.pool.size:
            picked = self._pick("compute")
            if picked is None:
                return
            profile, row = picked
            conn = self.registry.conn(profile)
            if row["type"] not in COMPUTE_HANDLERS:
                jobs_db.mark_failed(conn, row["id"], f"unknown job type {row['type']!r}")
                continue
            jobs_db.mark_running(conn, row["id"])
            job_id = id_to_str(row["id"])
            self.in_flight[job_id] = profile
            self.pool.submit(
                ComputeRequest(
                    job_id=job_id,
                    profile=profile,
                    type=row["type"],
                    params=json.loads(row["params"]),
                )
            )

    def _drain_pool(self) -> None:
        for msg in self.pool.poll():
            profile = self.in_flight.get(msg.job_id)
            if profile is None:
                continue
            if msg.kind != "progress":
                self.in_flight.pop(msg.job_id, None)
            try:
                conn = self.registry.conn(profile)
            except ProfileNotFound:
                continue  # profile deleted while the job was running
            job_id = id_from_str(msg.job_id)
            if msg.kind == "progress":
                jobs_db.set_progress(conn, job_id, msg.payload)
            elif msg.kind == "result":
                self._finish(conn, job_id, msg.payload)
            else:
                jobs_db.record_failure(conn, job_id, msg.payload.get("error", "unknown error"))

    @staticmethod
    def _finish(conn: sqlite3.Connection, job_id: bytes, result: dict) -> None:
        row = jobs_db.get(conn, job_id)
        if row is None:
            return
        progress = json.loads(row["progress"])
        progress["result"] = result
        jobs_db.set_progress(conn, job_id, progress)
        jobs_db.mark_done(conn, job_id)

    # -- io ----------------------------------------------------------------------------

    def _dispatch_io(self) -> None:
        if self._io_task is not None and not self._io_task.done():
            return
        self._io_task = None
        while True:
            picked = self._pick("io")
            if picked is None:
                return
            profile, row = picked
            conn = self.registry.conn(profile)
            handler = self.io_handlers.get(row["type"])
            if handler is None:
                jobs_db.mark_failed(conn, row["id"], f"unknown job type {row['type']!r}")
                continue
            jobs_db.mark_running(conn, row["id"])
            self._io_task = asyncio.create_task(
                self._run_io(profile, row["id"], row["type"], json.loads(row["params"]), handler)
            )
            return

    async def _run_io(
        self, profile: str, job_id: bytes, type_: str, params: dict, handler: IoHandler
    ) -> None:
        conn = self.registry.conn(profile)
        loop = asyncio.get_running_loop()

        def report(progress: dict) -> None:
            loop.call_soon_threadsafe(jobs_db.set_progress, conn, job_id, progress)

        ctx = IoContext(
            profile=profile,
            paths=self.registry.paths(profile),
            backup_dir=self.backup_dir,
            global_db_path=self.registry.global_db_path,
            settings=settings_db.all(conn),
            params=params,
            report=report,
        )
        try:
            result = await asyncio.to_thread(handler, ctx)
        except Exception as exc:  # noqa: BLE001 - recorded on the job, never propagated
            log.warning("io job %s (%s) failed: %s", id_to_str(job_id), type_, exc)
            if self.registry.exists(profile):
                jobs_db.record_failure(conn, job_id, f"{type(exc).__name__}: {exc}")
            return
        if self.registry.exists(profile):
            self._finish(conn, job_id, result)

    # -- planners ----------------------------------------------------------------------

    def _plan(self) -> None:
        now = time.monotonic()
        if self._last_plan is not None and now - self._last_plan < self.plan_interval:
            return
        self._last_plan = now
        for planner in self.planners:
            try:
                planner(self.registry)
            except Exception:  # noqa: BLE001
                log.exception("planner %r failed", planner)
```

```python
"""Backup job (design §9.1): SQLite online backup, integrity check, retention, scheduling.

Runs in the scheduler's io worker thread, so it opens its own connections from paths and
never touches the registry's connections.
"""

from __future__ import annotations

import sqlite3
from datetime import datetime, timedelta, timezone
from pathlib import Path

from visualstore.db import jobs as jobs_db
from visualstore.db import settings as settings_db
from visualstore.jobs.scheduler import IoContext
from visualstore.jobs.types import PRIORITY_MAINTENANCE
from visualstore.profiles import ProfileRegistry

TARGETS = ("metadata", "vectors")
PREFIX = {"metadata": "visualstore", "vectors": "vectors"}
_STAMP = "%Y%m%dT%H%M%SZ"


class BackupError(Exception):
    pass


# -- file names -----------------------------------------------------------------------


def backup_file_name(target: str, when: datetime) -> str:
    return f"{PREFIX[target]}-{when.astimezone(timezone.utc).strftime(_STAMP)}.db"


def parse_backup_time(path: Path) -> datetime | None:
    stem = path.name
    if not stem.endswith(".db"):
        return None
    for prefix in PREFIX.values():
        head = f"{prefix}-"
        if stem.startswith(head):
            try:
                return datetime.strptime(stem[len(head) : -3], _STAMP).replace(tzinfo=timezone.utc)
            except ValueError:
                return None
    return None


def _target_of(path: Path) -> str | None:
    for target, prefix in PREFIX.items():
        if path.name.startswith(f"{prefix}-"):
            return target
    return None


def list_backups(backup_dir: Path, profile: str) -> list[dict]:
    directory = backup_dir / profile
    if not directory.is_dir():
        return []
    found = []
    for path in directory.iterdir():
        when = parse_backup_time(path)
        target = _target_of(path)
        if when is None or target is None:
            continue
        found.append(
            {"target": target, "file": path.name, "size": path.stat().st_size,
             "time": when.isoformat()}
        )
    found.sort(key=lambda d: d["time"], reverse=True)
    return found


def latest_backup_time(backup_dir: Path, profile: str, target: str) -> datetime | None:
    times = [
        datetime.fromisoformat(d["time"])
        for d in list_backups(backup_dir, profile)
        if d["target"] == target
    ]
    return max(times) if times else None


# -- the job ---------------------------------------------------------------------------


def _copy_sqlite(src: Path, dest: Path) -> None:
    """Online backup into dest via a temp file; the result includes everything in the WAL."""
    tmp = dest.with_suffix(".tmp")
    source = sqlite3.connect(src)
    try:
        target = sqlite3.connect(tmp)
        try:
            source.backup(target)
        finally:
            target.close()
    finally:
        source.close()
    tmp.replace(dest)


def _verify(path: Path) -> None:
    try:
        conn = sqlite3.connect(path)
        try:
            row = conn.execute("PRAGMA integrity_check").fetchone()
        finally:
            conn.close()
        ok = row is not None and row[0] == "ok"
    except sqlite3.DatabaseError:
        ok = False
    if not ok:
        path.unlink(missing_ok=True)
        raise BackupError(f"integrity check failed on backup copy {path.name}; copy deleted")


def _prune(directory: Path, target: str, keep: int) -> list[Path]:
    files = sorted(directory.glob(f"{PREFIX[target]}-*.db"), key=lambda p: p.name)
    doomed = files[: max(0, len(files) - keep)]
    for path in doomed:
        path.unlink()
    return doomed


def run_backup(ctx: IoContext) -> dict:
    targets = list(ctx.params.get("targets") or TARGETS)
    for target in targets:
        if target not in TARGETS:
            raise BackupError(f"unknown backup target {target!r}")
    sources = {"metadata": ctx.paths.metadata_db, "vectors": ctx.paths.vectors_db}
    dest_dir = ctx.backup_dir / ctx.profile
    dest_dir.mkdir(parents=True, exist_ok=True)
    now = datetime.now(timezone.utc)
    total = len(targets) + 1
    written: list[str] = []
    for i, target in enumerate(targets, start=1):
        dest = dest_dir / backup_file_name(target, now)
        _copy_sqlite(sources[target], dest)
        _verify(dest)
        _prune(dest_dir, target, int(ctx.settings[f"backup.{target}.keep"]))
        written.append(str(dest))
        ctx.report({"done": i, "total": total, "message": f"backed up {target}"})
    ctx.backup_dir.mkdir(parents=True, exist_ok=True)
    _copy_sqlite(ctx.global_db_path, ctx.backup_dir / "global.db")
    ctx.report({"done": total, "total": total, "message": "finished"})
    return {"files": written}


# -- scheduling ------------------------------------------------------------------------


def due_targets(backup_dir: Path, profile: str, settings: dict, now: datetime) -> list[str]:
    due = []
    for target in TARGETS:
        latest = latest_backup_time(backup_dir, profile, target)
        interval = timedelta(hours=int(settings[f"backup.{target}.interval_hours"]))
        if latest is None or now - latest >= interval:
            due.append(target)
    return due


def plan_backups(registry: ProfileRegistry, backup_dir: Path, now: datetime | None = None) -> int:
    """Enqueue a backup job for every profile with an overdue target. Returns jobs enqueued."""
    now = now or datetime.now(timezone.utc)
    enqueued = 0
    for name in registry.names():
        conn = registry.conn(name)
        if jobs_db.has_active(conn, "backup"):
            continue
        targets = due_targets(backup_dir, name, settings_db.all(conn), now)
        if not targets:
            continue
        jobs_db.enqueue(
            conn, type="backup", kind="io", params={"targets": targets},
            priority=PRIORITY_MAINTENANCE,
        )
        enqueued += 1
    return enqueued
```

```python
"""Single-password login (design §9.2)."""

from fastapi import APIRouter, HTTPException, Request, Response
from pydantic import BaseModel

from visualstore.api.deps import COOKIE, get_state
from visualstore.auth import password_matches

router = APIRouter(prefix="/api/auth", tags=["auth"])


class LoginRequest(BaseModel):
    password: str


def _client_key(request: Request) -> str:
    return request.client.host if request.client else "unknown"


@router.post("/login")
def login(body: LoginRequest, request: Request, response: Response) -> dict:
    state = get_state(request)
    key = _client_key(request)
    if not state.limiter.allowed(key):
        raise HTTPException(status_code=429, detail="Too many failed logins. Try again in a minute.")
    if not password_matches(state.config.password, body.password):
        state.limiter.record_failure(key)
        raise HTTPException(status_code=401, detail="Wrong password.")
    state.limiter.reset(key)
    response.set_cookie(
        COOKIE,
        state.signer.issue(),
        max_age=state.signer.ttl_seconds,
        httponly=True,
        samesite="lax",
        path="/",
    )
    return {"ok": True}


@router.post("/logout")
def logout(response: Response) -> dict:
    response.delete_cookie(COOKIE, path="/")
    return {"ok": True}


@router.get("/me")
def me(request: Request) -> dict:
    token = request.cookies.get(COOKIE)
    state = get_state(request)
    return {"authenticated": bool(token and state.signer.verify(token))}
```

```python
"""FastAPI assembly: opens the registry, starts the pool and scheduler, mounts routers."""

from __future__ import annotations

from contextlib import asynccontextmanager
from dataclasses import dataclass
from functools import partial
from pathlib import Path

from fastapi import FastAPI, Request
from fastapi.responses import JSONResponse

from visualstore import __version__
from visualstore.api import auth as auth_api
from visualstore.api import system as system_api
from visualstore.auth import LoginRateLimiter, SessionSigner
from visualstore.config import Config
from visualstore.jobs.compute.pool import ComputePool
from visualstore.jobs.io import IO_HANDLERS
from visualstore.jobs.io.backup import plan_backups
from visualstore.jobs.scheduler import Scheduler
from visualstore.profiles import ProfileError, ProfileNotFound, ProfileRegistry


@dataclass
class AppState:
    config: Config
    registry: ProfileRegistry
    pool: ComputePool
    scheduler: Scheduler
    signer: SessionSigner
    limiter: LoginRateLimiter


def create_app(config: Config, static_dir: Path | None = None) -> FastAPI:
    @asynccontextmanager
    async def lifespan(app: FastAPI):
        registry = ProfileRegistry(config.data_dir)
        registry.open()
        signer = SessionSigner(registry.secret("session_key"))
        pool = ComputePool(config.compute_processes)
        pool.start()
        scheduler = Scheduler(
            registry,
            pool,
            io_handlers=IO_HANDLERS,
            backup_dir=config.backup_dir,
            planners=[partial(plan_backups, backup_dir=config.backup_dir)],
        )
        scheduler.requeue_interrupted()
        await scheduler.start()
        app.state.vs = AppState(
            config=config,
            registry=registry,
            pool=pool,
            scheduler=scheduler,
            signer=signer,
            limiter=LoginRateLimiter(),
        )
        try:
            yield
        finally:
            await scheduler.stop()
            pool.stop()
            registry.close()

    app = FastAPI(title="VisualStore", version=__version__, lifespan=lifespan)

    @app.exception_handler(ProfileNotFound)
    async def _profile_not_found(request: Request, exc: ProfileNotFound) -> JSONResponse:
        return JSONResponse(status_code=404, content={"detail": str(exc)})

    @app.exception_handler(ProfileError)
    async def _profile_error(request: Request, exc: ProfileError) -> JSONResponse:
        return JSONResponse(status_code=400, content={"detail": str(exc)})

    app.include_router(auth_api.router)
    app.include_router(system_api.router)
    # Task 11 and Task 12 add their routers here. Task 14 adds static files after the routers.
    return app
```

```python
    return [ProfileOut.of(p) for p in get_state(request).registry.list()]
```

```python
"""Job queue API (design §6, §8.1 Jobs and settings page)."""

import uuid

from fastapi import APIRouter, Depends, HTTPException, Request
from pydantic import BaseModel

from visualstore.api.deps import get_profile, get_state, require_auth
from visualstore.db import jobs as jobs_db
from visualstore.jobs.types import KIND_OF, PRIORITY_USER

router = APIRouter(prefix="/api/p/{name}/jobs", tags=["jobs"], dependencies=[Depends(require_auth)])


class CreateJob(BaseModel):
    type: str
    params: dict = {}
    priority: int = PRIORITY_USER


def _job_or_404(conn, job_id: str):
    try:
        raw = uuid.UUID(job_id).bytes
    except ValueError:
        raise HTTPException(status_code=404, detail="No such job.") from None
    row = jobs_db.get(conn, raw)
    if row is None:
        raise HTTPException(status_code=404, detail="No such job.")
    return raw, row


@router.get("")
def list_jobs(request: Request, name: str = Depends(get_profile), state: str | None = None,
              limit: int = 100) -> list[dict]:
    conn = get_state(request).registry.conn(name)
    return [jobs_db.to_dict(r) for r in jobs_db.list_jobs(conn, state=state, limit=limit)]


@router.post("", status_code=201)
def create_job(body: CreateJob, request: Request, name: str = Depends(get_profile)) -> dict:
    kind = KIND_OF.get(body.type)
    if kind is None:
        raise HTTPException(status_code=400, detail=f"Unknown job type '{body.type}'.")
    conn = get_state(request).registry.conn(name)
    job_id = jobs_db.enqueue(conn, type=body.type, kind=kind, params=body.params,
                             priority=body.priority)
    return jobs_db.to_dict(jobs_db.get(conn, job_id))


@router.get("/{job_id}")
def get_job(job_id: str, request: Request, name: str = Depends(get_profile)) -> dict:
    conn = get_state(request).registry.conn(name)
    _, row = _job_or_404(conn, job_id)
    return jobs_db.to_dict(row)


@router.post("/{job_id}/retry")
def retry_job(job_id: str, request: Request, name: str = Depends(get_profile)) -> dict:
    conn = get_state(request).registry.conn(name)
    raw, _ = _job_or_404(conn, job_id)
    if not jobs_db.retry(conn, raw):
        raise HTTPException(status_code=409, detail="Only failed jobs can be retried.")
    return jobs_db.to_dict(jobs_db.get(conn, raw))


@router.post("/{job_id}/cancel")
def cancel_job(job_id: str, request: Request, name: str = Depends(get_profile)) -> dict:
    conn = get_state(request).registry.conn(name)
    raw, _ = _job_or_404(conn, job_id)
    if not jobs_db.cancel(conn, raw):
        raise HTTPException(status_code=409, detail="Only queued jobs can be cancelled.")
    return jobs_db.to_dict(jobs_db.get(conn, raw))
```

```ts
export class ApiError extends Error {
  constructor(
    public status: number,
    message: string,
  ) {
    super(message);
  }
}

export class Unauthorized extends ApiError {
  constructor() {
    super(401, "Not logged in.");
  }
}

export async function api<T>(
  path: string,
  init: RequestInit = {},
  fetchImpl: typeof fetch = fetch,
): Promise<T> {
  const response = await fetchImpl(path, {
    credentials: "same-origin",
    ...init,
    headers: { "Content-Type": "application/json", ...(init.headers ?? {}) },
  });
  if (response.status === 401) throw new Unauthorized();
  if (!response.ok) {
    let detail: string = response.statusText;
    try {
      const body = (await response.json()) as { detail?: unknown };
      if (body.detail !== undefined) detail = String(body.detail);
    } catch {
      /* body was not JSON; keep the status text */
    }
    throw new ApiError(response.status, detail);
  }
  if (response.status === 204) return undefined as T;
  return (await response.json()) as T;
}

const withBody = (method: string, body?: unknown): RequestInit => ({
  method,
  body: body === undefined ? undefined : JSON.stringify(body),
});

export const get = <T>(path: string) => api<T>(path);
export const post = <T>(path: string, body?: unknown) => api<T>(path, withBody("POST", body));
export const put = <T>(path: string, body?: unknown) => api<T>(path, withBody("PUT", body));
export const patch = <T>(path: string, body?: unknown) => api<T>(path, withBody("PATCH", body));
export const del = <T>(path: string, body?: unknown) => api<T>(path, withBody("DELETE", body));
```

```tsx
function formatBytes(n: number): string {
  if (n < 1024) return `${n} B`;
  const units = ["KB", "MB", "GB", "TB"];
  let value = n / 1024;
  let i = 0;
  while (value >= 1024 && i < units.length - 1) {
    value /= 1024;
    i++;
  }
  return `${value.toFixed(1)} ${units[i]}`;
}

export default function Profiles() {

    void get<SystemStatus>("/api/system/status").then(setStatus);
  }, [profiles]);

    for (const p of profiles) {
      void get<{ bytes: number }>(`/api/profiles/${p.name}/usage`).then((u) =>
        setUsage((prev) => ({ ...prev, [p.name]: u.bytes })),
```

```python
DEFAULT_STATIC_DIR = Path(__file__).parent / "static"


def _mount_static(app: FastAPI, static_dir: Path) -> None:
    """Serve the frontend build. Registered after every API router so /api keeps its 404s."""
    index = static_dir / "index.html"
    if not index.is_file():
        return
    assets = static_dir / "assets"
    if assets.is_dir():
        app.mount("/assets", StaticFiles(directory=assets), name="assets")
    root = static_dir.resolve()

    @app.get("/{path:path}", include_in_schema=False)
    async def spa(path: str) -> FileResponse:
        if path.startswith("api/") or path == "api":
            raise HTTPException(status_code=404, detail="Not found.")
        candidate = (static_dir / path).resolve()
        if path and candidate.is_file() and candidate.is_relative_to(root):
            return FileResponse(candidate)
        return FileResponse(index)
```

- [ ] **Step 6: Write the publishing workflow**

`.github/workflows/docker-publish.yml`:

```yaml
name: Build and publish Docker image

# Manual trigger only. The version comes from pyproject.toml unless typed into the form.
on:
  workflow_dispatch:
    inputs:
      version:
        description: "Version tag to publish. Leave empty to use [project].version from pyproject.toml."
        required: false

env:
  IMAGE: ghcr.io/secretnest/visualstore
  # ACR_REGISTRY is the Alibaba Cloud registry host (org secret); the repository path is fixed.
  ACR_IMAGE: ${{ secrets.ACR_REGISTRY }}/secretnest/visualstore

jobs:
  build-and-push:
    runs-on: ubuntu-latest
    timeout-minutes: 60
    permissions:
      contents: read
      packages: write
    steps:
      - uses: actions/checkout@v4

      - uses: docker/setup-qemu-action@v3
      - uses: docker/setup-buildx-action@v3

      - name: Log in to GHCR
        uses: docker/login-action@v3
        with:
          registry: ghcr.io
          username: ${{ github.actor }}
          password: ${{ secrets.GITHUB_TOKEN }}

      - name: Log in to ACR
        uses: docker/login-action@v3
        with:
          registry: ${{ secrets.ACR_REGISTRY }}
          username: ${{ secrets.ACR_USERNAME }}
          password: ${{ secrets.ACR_PASSWORD }}

      - name: Resolve version
        id: version
        env:
          INPUT_VERSION: ${{ inputs.version }}
        run: |
          set -euo pipefail
          v="$INPUT_VERSION"
          if [ -z "$v" ]; then
            v="$(sed -n 's/^version = "\(.*\)"$/\1/p' pyproject.toml | head -1)"
          fi
          case "$v" in
            '') echo "::error::No version found in pyproject.toml and none supplied."; exit 1 ;;
            *[!0-9.]*|.*|*.) echo "::error::Version '$v' is not a dotted numeric version."; exit 1 ;;
          esac
          echo "version=$v" >> "$GITHUB_OUTPUT"

      - name: Compute tags
        id: meta
        uses: docker/metadata-action@v5
        with:
          images: |
            ${{ env.IMAGE }}
            ${{ env.ACR_IMAGE }}
          tags: |
            type=raw,value=${{ steps.version.outputs.version }}
            type=raw,value=latest

      - name: Build and push (amd64 + arm64)
        uses: docker/build-push-action@v6
        with:
          context: .
          file: docker/Dockerfile
          platforms: linux/amd64,linux/arm64
          push: true
          tags: ${{ steps.meta.outputs.tags }}
          labels: ${{ steps.meta.outputs.labels }}
          # Attestation manifests are rejected by ACR ("unknown manifest class"), so both stay off.
          provenance: false
          sbom: false
          # Cache lives in GHCR; the type=gha export runs after the push and has stalled builds.
          cache-from: type=registry,ref=${{ env.IMAGE }}:buildcache
          cache-to: type=registry,ref=${{ env.IMAGE }}:buildcache,mode=max,image-manifest=true,oci-mediatypes=true,ignore-error=true
```
