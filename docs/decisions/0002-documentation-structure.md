# ADR-0002 · One documentation tree, in English, under `docs/`

Date: 2026-11-06
Status: accepted

## Context

The v1 repository accumulated two documentation trees: the hand-written `doc/` for users and a `docs/superpowers/` tree generated by the Superpowers Claude Code workflow (specs and plans). The user asked that this repository keep exactly one tree and that workflow artifacts not be committed as a separate structure.

The original design document was written in Chinese, while v1's README and user documentation are English and the repository is public on GitHub. The user stated that English is acceptable for the design documents as well.

## Decision

- `docs/` is the only documentation tree. It has four parts: `design/` (the specification, by chapter), `decisions/` (ADRs), `plans/` (one implementation plan per milestone), and `user/` (end-user documentation, created in milestone 6).
- Specifications produced during design work go into `docs/design/`, not `docs/superpowers/specs/`. Implementation plans go into `docs/plans/`, not `docs/superpowers/plans/`. `docs/superpowers/` is listed in `.gitignore` so that tooling defaults cannot reintroduce it by accident.
- All documentation, including design and ADRs, is written in English. Conversation with the user may continue in Chinese; what lands in the repository is English.
- The single-file design that seeded this repository (`2026-11-02-imagestore-v2-design.md`) was split into the chapters under `docs/design/` and then deleted. The chapters preserve its section numbering.

## Consequences

- One place to look, one language, no synchronisation between parallel trees.
- The Superpowers workflow still runs; only its output locations differ. `CLAUDE.md` at the repository root states the locations so that any agent session follows them.
- Translating the original design introduced a small risk of drift. The chapters were produced from the final confirmed text; any later discrepancy found against the user's understanding is resolved in favour of the user's confirmed decisions and fixed in the chapter.
