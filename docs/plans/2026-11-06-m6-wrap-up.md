# Milestone 6 · Wrap-up — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

> This plan was expanded from the task-level plan of the same name after milestone 5 shipped. The "Decide before expanding" items are decided as recorded in [ADR-0008](../decisions/0008-m6-implementation-choices.md) (written in Task 1): `index.quantization` defaults to `f16` with `i8` available; PCA is per profile, trained on a sample at rebuild time, off by default; the image runs as a non-root user chosen with `PUID`/`PGID` by an entrypoint that adjusts ownership only of an empty `/data`.

**Goal:** VisualStore is operable at scale and by someone who did not write it: index memory is a setting, the data directory keeps itself tidy and consistent across restores, the container runs non-root with a meaningful health check, CI exercises the whole pipeline including the browser, the deferred minors of earlier reviews are closed or retired, and `docs/user/` explains deployment, initialisation and migration, restore, import and review.

**Architecture:** No new subsystems. `rebuild_index`/`build_index`/`match` honour two index options (`index.quantization`, `index.pca_dims`) recorded in `index_meta`; a settings change of either enqueues a rebuild. A `maintenance` io job (weekly planner) removes orphan thumbnails/previews/frame images, drops frame rows of unknown files, runs ANALYZE and a thresholded VACUUM. Start-up gains a consistency pass between `visualstore.db` and `vectors.db`. The scheduler records a heartbeat that `/api/system/health` exposes for the Docker HEALTHCHECK. The image gets an entrypoint that drops privileges and a Python pre-flight that fails fast on an unwritable data directory. Tests add a migration rehearsal and a restore rehearsal; CI adds a Playwright job.

**Tech Stack:** Python 3.12, numpy (SVD for PCA), usearch (`dtype="i8"`), FastAPI, Docker (`setpriv` from util-linux), GitHub Actions, Playwright. No new dependencies.

**Spec:** [02 §3.1](../design/02-architecture.md#31-initialisation-and-migration), [04 §6.2 maintenance](../design/04-jobs.md), [07 §9.1, §9.4, §9.5](../design/07-operations.md), [10 Testing](../design/10-testing.md), [00 §1.3](../design/00-overview.md#13-acceptance-criteria), [11 §13 item 6](../design/11-roadmap.md#13-milestones).

## Review Focus

1. **Changing `index.quantization` or `index.pca_dims`** must trigger a rebuild and must not change any stored vector in `vectors.db`; the rebuilt index must answer searches for the same neighbours as before (within quantisation error). (Task 1.)

5. **The HEALTHCHECK must fail when the scheduler loop has not ticked for 60 s**, not merely when HTTP answers. (Task 4.)

```markdown
# ADR-0008: Milestone 6 implementation choices

Date: 2026-11-07 · Status: accepted

## Context

The milestone 6 task-level plan listed decisions to take before expansion: index quantisation default, PCA strategy, and the non-root container user.

## Decisions

- **Quantisation is a setting, default `f16`.** `index.quantization` accepts `f16` (2 bytes per dimension, exact enough for the bands) and `i8` (1 byte, for tight memory). `scripts/measure_index.py` reports size and recall for a profile's own vectors so the operator can decide with numbers; the default stays `f16` until a measurement on real data says otherwise.
- **PCA is per profile, trained at rebuild time, off by default.** `index.pca_dims` (0 = off) makes `rebuild_index` fit a projection on a sample of up to 100 000 of the profile's vectors (numpy SVD), save it as `pca.npz` beside the index, and build the index in the reduced space; `match` projects new vectors and queries with the same file. Vectors in `vectors.db` are never changed, so switching PCA off or changing the dimension is just another rebuild. A fixed projection per model would need shipping and versioning more artefacts for a feature few installations will turn on.
- **Changing either option enqueues a rebuild from the settings endpoint**; start-up also compares `index_meta` with the settings and rebuilds when they differ (so a restored database with other settings heals itself).
- **Non-root container with `PUID`/`PGID`.** The image starts as root in `docker/entrypoint.sh`, which creates the target user if needed, changes the ownership of `/data` and `/backups` only when they are empty (an existing data directory is never chowned: it may be on a volume the operator manages), and drops privileges with `setpriv`. A Python pre-flight then verifies both directories are writable and exits with a clear message otherwise, before the scheduler starts.
- **Health = HTTP + scheduler heartbeat.** `/api/system/health` answers 503 when the scheduler has not ticked for 60 s; the Dockerfile HEALTHCHECK probes it with Python's urllib (no curl in the image).
- **Maintenance is a weekly io job** at maintenance priority: orphan thumbnails/previews/frame images, frame rows of unknown files, ANALYZE, and VACUUM only above a free-page ratio.
- **Retry backoff**: a failed attempt re-queues the job with `not_before = now + 30 s × attempts`; the picker skips jobs whose `not_before` is in the future.

## Consequences

- `pca.npz` and `index.usearch` are derived data like thumbnails; backups skip them.
- The measurement script and the performance numbers on the user's library are operator steps; the design records where the numbers go.
```

```python
import numpy as np
import pytest

from visualstore.index import pca


def unit_rows(n, dim, seed=0):
    rng = np.random.default_rng(seed)
    v = rng.normal(size=(n, dim)).astype(np.float32)
    v[:, : dim // 4] *= 5  # a few dominant directions, so PCA has something to keep
    return v / np.linalg.norm(v, axis=1, keepdims=True)


def test_fit_project_round_trip_keeps_neighbours(tmp_path):
    vectors = unit_rows(2000, 64)
    p = pca.fit(vectors, 16, sample=500)
    assert p.dims == 16 and p.components.shape == (16, 64) and p.mean.shape == (64,)
    projected = pca.project(p, vectors)
    assert projected.shape == (2000, 16)
    assert np.allclose(np.linalg.norm(projected, axis=1), 1.0, atol=1e-4)
    # nearest neighbour of row 0 in the original space survives the projection most of the time
    exact = np.argsort(-(vectors @ vectors[0]))[1:6]
    reduced = np.argsort(-(projected @ projected[0]))[1:6]
    assert len(set(exact) & set(reduced)) >= 2
    pca.save(p, tmp_path / "pca.npz")
    loaded = pca.load(tmp_path / "pca.npz")
    assert np.allclose(loaded.components, p.components) and np.allclose(loaded.mean, p.mean)


def test_fit_rejects_impossible_dims():
    vectors = unit_rows(50, 8)
    with pytest.raises(ValueError):
        pca.fit(vectors, 8, sample=50)
    with pytest.raises(ValueError):
        pca.fit(vectors, 0, sample=50)
    with pytest.raises(ValueError):
        pca.fit(vectors[:3], 4, sample=50)  # fewer rows than dims
```

`visualstore/index/pca.py`:

```python
"""Per-profile PCA for the vector index (design §9.5, ADR-0008). Stored vectors stay raw."""

from __future__ import annotations

from dataclasses import dataclass
from pathlib import Path

import numpy as np


@dataclass(frozen=True)
class Projection:
    mean: np.ndarray  # (dim,)
    components: np.ndarray  # (dims, dim)

    @property
    def dims(self) -> int:
        return int(self.components.shape[0])


def fit(vectors: np.ndarray, dims: int, sample: int = 100_000, seed: int = 0) -> Projection:
    rows, dim = vectors.shape
    if dims < 1 or dims >= dim:
        raise ValueError(f"pca dims must be between 1 and {dim - 1}, got {dims}")
    if rows < dims:
        raise ValueError(f"need at least {dims} vectors to fit {dims} components, have {rows}")
    if rows > sample:
        picked = np.random.default_rng(seed).choice(rows, size=sample, replace=False)
        vectors = vectors[np.sort(picked)]
    data = vectors.astype(np.float32)
    mean = data.mean(axis=0)
    _, _, vt = np.linalg.svd(data - mean, full_matrices=False)
    return Projection(mean=mean, components=np.ascontiguousarray(vt[:dims]))


def project(p: Projection, vectors: np.ndarray) -> np.ndarray:
    out = (np.asarray(vectors, dtype=np.float32) - p.mean) @ p.components.T
    norms = np.linalg.norm(out, axis=1, keepdims=True)
    norms[norms == 0] = 1.0
    return np.ascontiguousarray(out / norms, dtype=np.float32)


def save(p: Projection, path: Path) -> None:
    path = Path(path)
    tmp = path.with_suffix(".tmp.npz")
    np.savez(tmp, mean=p.mean, components=p.components)
    tmp.replace(path)


def load(path: Path) -> Projection:
    data = np.load(path)
    return Projection(mean=data["mean"].astype(np.float32), components=data["components"].astype(np.float32))
```

```python
def index_options(settings: dict, paths, model_dim: int) -> dict:
    """What a compute child needs to open or build the profile index (ADR-0008)."""
    dims = int(settings.get("index.pca_dims", 0))
    return {
        "quantization": str(settings.get("index.quantization", "f16")),
        "pca_dims": dims,
        "pca_path": str(paths.root / "pca.npz") if dims else None,

    }
```

```python
"""Measure index size and recall for the quantisation / PCA options on a profile's own
vectors (ADR-0008). Read-only on the database.

    uv run python scripts/measure_index.py --vectors /data/profiles/<name>/vectors.db \
        --model sscd-resnet50-512-v1 --sample 20000 --k 10 --pca 256
"""

from __future__ import annotations

import argparse
import sqlite3
import tempfile
import time
from pathlib import Path

import numpy as np

from visualstore.index import pca
from visualstore.index.usearch_index import VectorIndex


def load_vectors(db: Path, model_id: str, sample: int, seed: int = 0) -> np.ndarray:
    conn = sqlite3.connect(f"file:{db}?mode=ro", uri=True)
    rows = conn.execute("SELECT vector FROM fingerprint WHERE model_id = ?", (model_id,)).fetchall()
    conn.close()
    if not rows:
        raise SystemExit(f"no vectors for {model_id} in {db}")
    vectors = np.array([np.frombuffer(r[0], dtype=np.float16) for r in rows]).astype(np.float32)
    if len(vectors) > sample:
        picked = np.random.default_rng(seed).choice(len(vectors), size=sample, replace=False)
        vectors = vectors[np.sort(picked)]
    return vectors


def exact_neighbours(vectors: np.ndarray, queries: np.ndarray, k: int) -> np.ndarray:
    scores = queries @ vectors.T
    return np.argsort(-scores, axis=1)[:, 1 : k + 1]  # skip self


def measure(vectors: np.ndarray, k: int, pca_dims: int | None, queries: int = 200) -> list[dict]:
    rng = np.random.default_rng(1)
    q_idx = rng.choice(len(vectors), size=min(queries, len(vectors)), replace=False)
    truth = exact_neighbours(vectors, vectors[q_idx], k)
    variants = [("f16", None), ("i8", None)]
    if pca_dims:
        variants += [("f16", pca_dims), ("i8", pca_dims)]
    out = []
    for quantization, dims in variants:
        data = vectors
        if dims:
            data = pca.project(pca.fit(vectors, dims), vectors)
        started = time.perf_counter()
        index = VectorIndex.empty(data.shape[1], quantization)
        index.add(list(range(len(data))), data)
        build_s = time.perf_counter() - started
        with tempfile.TemporaryDirectory() as tmp:
            path = Path(tmp) / "index.usearch"
            index.save(path)
            size = path.stat().st_size
        hits = 0
        for row, qi in enumerate(q_idx):
            found = {key for key, _ in index.search(data[qi], k + 1) if key != qi}
            hits += len(found & set(truth[row].tolist()))
        out.append(
            {
                "variant": f"{quantization}" + (f"+pca{dims}" if dims else ""),
                "bytes": size,
                "build_s": round(build_s, 2),
                f"recall@{k}": round(hits / (len(q_idx) * k), 4),
            }
        )
    return out


def main() -> None:
    parser = argparse.ArgumentParser()
    parser.add_argument("--vectors", type=Path, required=True)
    parser.add_argument("--model", required=True)
    parser.add_argument("--sample", type=int, default=20_000)
    parser.add_argument("--k", type=int, default=10)
    parser.add_argument("--pca", type=int, default=0)
    args = parser.parse_args()
    vectors = load_vectors(args.vectors, args.model, args.sample)
    rows = measure(vectors, args.k, args.pca or None)
    keys = list(rows[0])
    print(" | ".join(keys))
    for r in rows:
        print(" | ".join(str(r[key]) for key in keys))


if __name__ == "__main__":
    main()
```

```python
"""Maintenance job (design §6.2): orphan derived files, frames of unknown files, ANALYZE,
and VACUUM when the free-page ratio justifies it. Idempotent; safe to interrupt."""

from __future__ import annotations

import sqlite3
from contextlib import closing
from pathlib import Path

from visualstore.db import fingerprints as fp
from visualstore.db import jobs as jobs_db
from visualstore.ids import id_from_str
from visualstore.jobs.scheduler import IoContext
from visualstore.jobs.types import PRIORITY_MAINTENANCE


def _known_ids(conn: sqlite3.Connection) -> set[bytes]:
    return {bytes(r["id"]) for r in conn.execute("SELECT id FROM file")}


def _id_of(path: Path) -> bytes | None:
    text = path.stem.split("-")[0] if path.parent.parent.name == "frames" else path.stem
    try:
        return id_from_str(text)
    except ValueError:
        return None


def _sweep(directory: Path, known: set[bytes], ctx: IoContext, label: str) -> int:
    removed = 0
    if not directory.is_dir():
        return 0
    for path in directory.rglob("*.webp"):
        owner = _id_of(path)
        if owner is None or owner in known:
            continue
        path.unlink(missing_ok=True)
        removed += 1
        if removed % 500 == 0:
            ctx.report({"done": removed, "total": 0, "message": f"{label}: {removed} removed"})
    return removed


def _free_ratio(conn: sqlite3.Connection) -> float:
    pages = conn.execute("PRAGMA page_count").fetchone()[0]
    free = conn.execute("PRAGMA freelist_count").fetchone()[0]
    return (free / pages) if pages else 0.0


def _vacuum_if_needed(conn: sqlite3.Connection, ratio: float) -> tuple[bool, float]:
    free = _free_ratio(conn)
    conn.execute("ANALYZE")
    if free > ratio:
        conn.isolation_level = None  # VACUUM cannot run inside a transaction
        conn.execute("VACUUM")
        conn.isolation_level = ""
        return True, free
    return False, free


def run_maintenance(ctx: IoContext) -> dict:
    ratio = float(ctx.settings.get("maintenance.vacuum_free_ratio", 0.2))
    with closing(ctx.open_metadata()) as conn, closing(ctx.open_vectors()) as vconn:
        known = _known_ids(conn)
        thumbs = _sweep(ctx.paths.thumbs, known, ctx, "thumbnails")
        frames_dir = ctx.paths.previews / "frames"
        frame_images = _sweep(frames_dir, known, ctx, "frame images")
        previews = 0
        for sub in ctx.paths.previews.iterdir() if ctx.paths.previews.is_dir() else []:
            if sub.name != "frames":
                previews += _sweep(sub, known, ctx, "previews")
        unknown = fp.file_ids_with_frames(vconn) - known
        unknown_frames = 0
        if unknown:
            unknown_frames = vconn.execute(
                f"SELECT COUNT(*) FROM fingerprint WHERE file_id IN ({','.join('?' * len(unknown))})",
                list(unknown),
            ).fetchone()[0]
            fp.delete_for_files(vconn, unknown)
            if not (jobs_db.has_active(conn, "rebuild_index") or jobs_db.has_active(conn, "build_index")):
                jobs_db.enqueue(conn, type="rebuild_index", kind="io", priority=PRIORITY_MAINTENANCE)
        vacuumed_meta, free_meta = _vacuum_if_needed(conn, ratio)
        vacuumed_vec, free_vec = _vacuum_if_needed(vconn, ratio)
    return {
        "orphan_thumbnails": thumbs,
        "orphan_previews": previews,
        "orphan_frame_images": frame_images,
        "unknown_file_frames": int(unknown_frames),
        "analyzed": True,
        "vacuumed": vacuumed_meta or vacuumed_vec,
        "free_ratio": round(max(free_meta, free_vec), 4),
    }
```

```python
"""Start-up pre-flight: the data and backup directories must be writable by this process,
otherwise the scheduler would loop on PermissionError (design §9.4, ADR-0008)."""

from __future__ import annotations

import os
import uuid
from pathlib import Path


class PreflightError(Exception):
    pass


def _owner(path: Path) -> str:
    try:
        st = path.stat()
        return f"uid {st.st_uid}, gid {st.st_gid}"
    except OSError:
        return "unknown owner"


def check_directories(data_dir: Path, backup_dir: Path) -> None:
    for label, directory in (("data", data_dir), ("backup", backup_dir)):
        try:
            directory.mkdir(parents=True, exist_ok=True)
            probe = directory / f".write-probe-{uuid.uuid4().hex}"
            probe.write_bytes(b"ok")
            probe.unlink()
        except OSError as exc:
            raise PreflightError(
                f"The {label} directory {directory} is not writable by this process"
                f" (uid {os.geteuid()}, gid {os.getegid()}; the directory belongs to"
                f" {_owner(directory)}): {exc}. Set PUID/PGID to the owner of the volume or"
                " change the directory's ownership, then restart."
            ) from exc
```

```bash
  mkdir -p "$dir"

done
exec setpriv --reuid="$PUID" --regid="$PGID" --init-groups "$@"
```

### Task 8: Deferred-minors sweep

**Files:**

Each item below is one RED→GREEN cycle; items marked *retire* get a line in ADR-0008 under "Deferred minors retired" instead of code.

- [ ] **8.1 Retry backoff** — migration `0003_job_not_before.sql`: `ALTER TABLE job ADD COLUMN not_before TEXT;`. `record_failure` sets `not_before = now + 30 s × attempts` when re-queuing (store ISO); `next_queued` adds `AND (not_before IS NULL OR not_before <= ?)` with `now_iso()`; `to_dict` exposes `not_before`; `retry()` (manual) clears it. Test in `tests/unit/test_jobs_db.py`: after one failure the job is not picked until the clock passes (`next_queued` takes an optional `now` for the test); the migration test's table list gains the column (check `tests/unit/test_migrate.py`).
- [ ] **8.2 Test-only `fail` job type gating** — keep `ping` (a harmless smoke job the UI could use) but remove `fail` from `KIND_OF` so the API refuses it (`400 Unknown job type`); the compute handler stays for the pool test (`test_compute_pool.py` submits it directly). Update `test_api_profile_scoped.py::test_failed_job_can_be_retried_and_queued_job_cancelled` to produce a failure another way: enqueue a `fingerprint` job through the API with a non-existent path and the fake model (it fails on the model check) — or simpler, insert a `fail` job with `jobs_db.enqueue` directly through `client.app.state.vs.registry.conn("a")` and keep the API-level assertions for retry/cancel.
- [ ] **8.3 Half-open profile creation** — `ProfileRegistry.create`: call `_open_profile(name)` (creates directories and both databases) **before** inserting the row; on failure remove the profile directory and re-raise. Test in `tests/unit/test_profiles.py`: monkeypatch `migrate` to raise once → no row, no directory.
- [ ] **8.4 `usage_bytes` caching** — `ProfileRegistry.usage_bytes(name)` caches per profile for 60 s (`self._usage: dict[str, tuple[float, int]]`); `delete` clears the entry. Test: two calls within the window do one walk (monkeypatch `Path.rglob` counting).
- [ ] **8.5 Backup file name second resolution** — `run_backup`: if the destination exists, append `-1`, `-2`, … before `.db` (`_unique` like the trash) so two backups within one second never overwrite; `parse_backup_time` tolerates the suffix. Test in `tests/unit/test_backup.py`.
- [ ] **8.6 Jobs list validation** — `GET /jobs`: `state` not in `jobs_db.STATES` → 400; `limit` clamped to 1..500. Test in `test_api_profile_scoped.py`.
- [ ] **8.7 Limiter pruning** — `LoginRateLimiter.record_failure` prunes every key's stale entries when the dict exceeds 1000 keys (so a scan of many addresses cannot grow memory). Test in `tests/unit/test_auth.py`.
- [ ] **8.8 Cookie `Secure`** — *retire*: VisualStore speaks plain HTTP behind the operator's proxy (README says so); a `Secure` cookie would break the documented deployment; recorded in ADR-0008.
- [ ] **8.9 Concurrent-writer backup test** — `tests/unit/test_backup.py`: run `run_backup` while another thread inserts rows in a loop; the copy passes `integrity_check` and the writer never fails (the online backup API handles it). Code change only if the test finds one.
- [ ] **8.10 401 redirect in polling pages** — `web/src/api.ts`: a module-level `let onUnauthorized: (() => void) | null` with `setUnauthorizedHandler(fn)`; `api()` calls it before throwing `Unauthorized`. `Layout` registers `() => navigate("/login", { replace: true })` in an effect (and unregisters on unmount). vitest: `api.test.ts` gains a case asserting the handler fires on 401.
